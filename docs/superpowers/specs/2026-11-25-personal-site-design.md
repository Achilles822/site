# 个人站点设计

日期：2026-11-25

## 目的

做一个中文个人站点。读者打开首页挑选文章，点进正文阅读，也可以从导航进入关于我。文章和关于我都是仓库里的 Markdown，由页面直接渲染。

成功时，本地可以打开首页、文章页和关于我。首页是带封面的卡片列表，置顶文章在最前并带有 `※`。正文来自 Markdown。视觉按 2026-11-25 对 https://www.christies.com/zh-cn/ 首页的实测字号和字重，用可授权的开源字体实现。没有数据库连接时，这三个页面仍然完整可用。

## 这一版做什么

- Next.js App Router 与 TypeScript。实现时使用当时的当前稳定版。
- 包管理用 pnpm。
- 样式是全局 CSS 变量，按下面的字号写死。不引入组件库，也不用另一套间距刻度去近似这些尺寸。
- 内容在 `content/` 的 Markdown 文件里。
- 安装 `@neondatabase/serverless`，提供 `.env.example` 里的 `DATABASE_URL`，以及 `lib/db.ts`。这一版没有任何查询。

## 这一版不做什么

以下各项只记在本文和后来的 `AGENTS.md` 里，不设计表，不写界面，不写查询：

- Google 登录。还没有 App ID。
- Neon 里的用户资料。
- Stripe 与购买记录。卖的是什么还没定。
- 付费墙。文章全部公开。
- MDX、Velite，以及在正文里嵌入 React 组件。
- 佳士得首页的拍卖轮播、搜索、部门导航和登录。

## 页面

主视口是 1440 宽的桌面。窄于 1100px 时，卡片改为一列。

| 路径 | 内容 |
| --- | --- |
| `/` | 全部文章的封面卡片。没有首屏口号。 |
| `/posts/[slug]` | 一篇文章。 |
| `/about` | 关于我。 |
| 未知地址 | 404。 |

顶栏一行，不吸顶。左侧站名「笔记」链到 `/`，右侧「关于我」链到 `/about`。站名使用衬线 24px、字重 300。导航使用无衬线 14px、字重 300。顶栏下有一条 1px、颜色 `#222222` 的线。站名来自一个常量，顶栏和浏览器标题都读它。

首页的主动作是点开一张卡片。整张卡片是一个链接，进入 `/posts/[slug]`。

## 内容文件

```text
content/about.md
content/posts/<slug>.md
public/covers/<file>
```

slug 是文件名，使用英文或拼音。`content/posts/first-note.md` 对应 `/posts/first-note`。中文标题写在文首，不写进文件名。

文章文首：

```yaml
---
title: 标题
date: 2026-11-25
description: 卡片上的摘要
cover: /covers/first-note.jpg
pinned: true
---
```

`pinned` 省略视为 `false`。`date` 是 `YYYY-MM-DD`。关于我只有 `title` 和正文，没有 `cover`、`date`、`pinned`。

仓库里放两篇示例文章和一篇短的关于我，方便替换。一篇示例置顶。示例不使用假照片：不写 `cover` 时，封面区是 `#e8e8e8` 画框。文案使用完整的中文句子，不用「标题」「描述」这类占位词。

## 读取与渲染

服务端组件用 `fs` 读取文件。`gray-matter` 拆开文首和正文。正文用 `react-markdown` 的同步 Markdown 组件渲染，并加上 `remark-gfm`。不启用 `rehype-raw`，Markdown 里的原始 HTML 不会变成页面 HTML。文章页和关于我共用这一套渲染。

列表排序：

1. `pinned: true` 的在前。多篇置顶时，置顶文章之间仍按日期从新到旧。
2. 其余按 `date` 从新到旧。
3. 日期相同按 slug 升序，保证顺序稳定。

`※` 只出现在首页卡片上，放在日期前面，与日期同一行、同一套 14px 无衬线字。文章页不重复这个记号。日期显示为 `2026年11月25日`。

卡片上的摘要使用文首 `description`，无衬线 16px、字重 400，不截断。

## 字体与版面

2026-11-25 实测佳士得中文站首页：卡片标题是 ABC Arizona Serif，24px、字重 300、行高 28.8px、颜色 `rgb(34, 34, 34)`、字距 normal；标签是 ABC Arizona Sans，14px、字重 300、行高 16.8px。ABC Arizona 是授权给佳士得使用的商业字体，不下载、不内联他们的字体文件。

本站用开源字体对齐这些角色和尺寸：

| 角色 | 拉丁字体 | 中文字体 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- | --- | --- |
| 顶栏站名、文章页标题、关于我标题 | Source Serif 4 | Noto Serif SC | 顶栏 24px；文章与关于我 40px | 300 | 1.2 |
| 卡片标题 | Source Serif 4 | Noto Serif SC | 24px | 300 | 1.2 |
| 日期、顶栏链接、置顶记号 | Source Sans 3 | Noto Sans SC | 14px | 300 | 1.2 |
| 卡片摘要 | Source Sans 3 | Noto Sans SC | 16px | 400 | 1.5 |
| 正文 | Source Sans 3 | Noto Sans SC | 18px | 400 | 1.7 |

文章页标题 40px 是从卡片标题往上的一档。佳士得文章页没有单独测量。正文行宽 38em。字体通过 `next/font` 引入。

文章页从上到下是标题、日期、封面、正文。有 `cover` 且文件存在时显示封面。`cover` 路径缺少文件时，显示 `#222222` 画框。没有 `cover` 时不显示封面区。文章页不重复摘要。关于我从上到下是标题和正文。

版面：

- 纸色 `#ffffff`，字色 `#222222`。没有第二种强调色。
- 内容宽度最多 1344px，左右各 48px。
- 不窄于 1100px 时三列，列间距 36px。窄于 1100px 时一列。
- 封面铺满格子宽度，高宽比 3:2。封面没有圆角、描边和阴影。
- 悬停时封面在 150ms 内透明度变为 0.92，布局不动。页面进入时没有出场动画。

## 组件与模块

| 单元 | 职责 |
| --- | --- |
| 顶栏 | 站名与「关于我」 |
| 文章卡片 | 封面、日期、置顶记号、标题、摘要，整卡可点 |
| Markdown 正文 | 把 Markdown 字符串渲染成页面内容 |
| `lib/posts.ts` | 扫描 `content/posts`，解析、校验、排序，按 slug 读取一篇 |
| `lib/markdown.tsx` | 共享的 Markdown 渲染 |
| `lib/db.ts` | 创建 Neon 客户端。没有调用方。缺少 `DATABASE_URL` 时，只有被调用才抛出明确错误 |
| `app/page.tsx` | 首页列表 |
| `app/posts/[slug]/page.tsx` | 文章页 |
| `app/about/page.tsx` | 关于我 |
| `app/not-found.tsx` | 404 |

## 失败

| 情况 | 结果 |
| --- | --- |
| 文章缺少 `title` 或 `date` | 抛出错误，这次请求失败。开发时能看到缺了哪个字段。不跳过该文件 |
| 缺少 `content/about.md`，或关于我缺少 `title` | 抛出错误，这次请求失败 |
| 文首写了 `cover`，但文件不在 `public/` 下 | 卡片和文章页仍可打开，封面区为 `#222222` 空画框 |
| 文首没有 `cover` | 首页卡片封面区为 `#e8e8e8` 画框。文章页不显示封面区 |
| slug 没有对应文件 | 404。衬线标题「找不到这篇文章」，下面一个「返回首页」文字链接 |
| `content/posts` 里没有文章 | 首页一句无衬线文字：「还没有文章。」 |
| 没有 `DATABASE_URL` | 首页、文章和关于我照常打开 |

## 文档顺序

实现计划的第一批只写文档，应用代码排在后面：

1. 本文。评审通过后再进入实现计划。
2. `AGENTS.md`：内容文件格式、上面的字体与尺寸、以及这一版不接登录、不建用户表、不接 Stripe、不写数据库查询。
3. `README.md`：如何安装、如何本地运行、文章放在哪里。

## 验收

- 用 Vitest 锁住排序：置顶在最前；置顶之间和未置顶之间都是日期从新到旧；日期相同按 slug 升序。
- 用 Vitest 锁住文首：缺少 `title` 或 `date` 时失败；没有 `cover` 时不失败。
- 页面完成后，在浏览器里走完首页、一篇文章、关于我，以及一个不存在的 slug。
